5. Factorial, Fibonacci and Binary Search

Algorithm
1. Start the program.
2. Define a recursive function fact(n):
   a. If n is 0 or 1, return 1.
   b. Otherwise, return n multiplied by fact(n-1).
3. Set n to 5 and call fact(n) to calculate the factorial recursively.
4. Calculate the factorial iteratively by multiplying the numbers from 1 through n.
5. Display both factorial values.
6. Generate the first five Fibonacci terms by calling the recursive fib() function for indices 0 through 4.
7. Initialize the sorted array, search key, lower bound, and upper bound for binary search.
8. Find the middle index of the current search range.
9. If the middle element equals the key, stop searching.
10. If the key is smaller, move the upper bound to mid-1; otherwise, move the lower bound to mid+1.
11. Display the middle index found by the search.
12. Stop the program.

C Program
#include <stdio.h>

int fact(int n) {
return n<=1 ? 1 : n*fact(n-1);
}

int fib(int n) {
return n<=1 ? n : fib(n-1)+fib(n-2);
}

int main() {
int n=5, i, f=1;
int a[]={10,20,30,40,50};
int l=0, r=4, m, x=30;

// Factorial
printf("Factorial Rec = %d\n",fact(n));
for(i=1;i<=n;i++) f*=i;
printf("Factorial Iter = %d\n",f);

// Fibonacci
printf("Fibonacci: ");
for(i=0;i<n;i++) printf("%d ",fib(i));

// Binary Search - Iteration
while(l<=r) {
    m=(l+r)/2;
    if(a[m]==x) break;
    if(x<a[m]) r=m-1;
    else l=m+1;
}
printf("\nBinary Search Iter = %d",m);
return 0;
}

Program Order
1. Factorial – Recursion and iteration
2. Fibonacci – Recursion
3. Binary Search – Iteration

Output
Factorial Rec = 120
Factorial Iter = 120
Fibonacci: 0 1 1 2 3
Binary Search Iter = 2

Result
Factorial, Fibonacci, and binary search were implemented successfully.
